# smart-electricity-billing-system
A Python OOP project that calculates electricity bills based on unit consumption and tiered pricing. It demonstrates classes, constructors, encapsulation, class attributes, and instance methods.
<br>
Topics Covered: 
<br>

1. Class and Objects
2. Constructor (__init__)
3. Class Attributes
4. Instance Attributes
5. Instance Methods
6. Encapsulation (Private Attributes)
7. Conditional Statements (if-elif-else)
8. User Input (input())
9. Exception Handling (try-except)
10. Mathematical Operations
11. Built-in Functions (min(), max())
12. Return Statements
13. Main Function
14. Dunder Method (__name__ == "__main__")
